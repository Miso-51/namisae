# 내 친구 남미새 만들기

신입사원 친구를 2년 동안 퇴근 후 스케줄로 키우는 픽셀 육성 게임.

- 친구 사진은 플레이하는 사람의 브라우저 안에서만 쓰이고 어디에도 업로드되지 않아요.
- 진행 상황은 브라우저에 자동 저장되고, MENU > 세이브 파일 저장으로 백업할 수 있어요.
